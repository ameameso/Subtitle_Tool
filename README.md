# Subtitle Tool (v1.3.1)

一个为研究员和创作者设计的全能字幕处理工具。支持提取、互转及专有的剪映 JSON 解析。

## 🛠️ 三大核心模式

1. **提取纯文本 (Extract)**
   - 目标：获取干净的文稿。
   - 支持：ASS/SRT -> TXT。
   - 特点：自动剥离所有时间轴和特效标签。

2. **字幕格式互转 (Convert)**
   - 目标：不同播放器/压制软件的格式兼容。
   - 支持：ASS ↔ SRT 双向互转。
   - 特点：保留精确时间轴，自动转换时间戳格式。

3. **剪映 JSON 转换 (CapCut)**
   - 目标：从剪映草稿中提取字幕。
   - 支持：JSON -> SRT。
   - 特点：解析微秒级存根，还原标准 SRT 时间序列。
