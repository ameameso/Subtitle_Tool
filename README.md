# 字幕提取工具

这是一个基于 Python 开发的轻量级桌面字幕提取工具。它可以帮助你快速从 `.ass` 或 `.srt` 字幕文件中提取纯文本内容，非常适合需要快速获取视频台词、歌词或进行文本分析的场景。

## 🌟 主要功能

- **多格式支持**：同步支持 `.ass` 和 `.srt` 两种主流字幕格式。
- **一键提取**：采用拖拽式交互，直接将文件拖入窗口即可自动生成同名 `.txt` 文件。
- **智能清洗**：
  - **ASS**：自动识别并剔除 `{\pos(x,y)}`、`{\i1}` 等样式标签。
  - **SRT**：自动过滤时间轴、序号及 HTML 标签（如 `<i>`）。
- **极简体验**：窗口始终置顶（Always on Top），方便从文件夹中拖入文件。

## 📂 目录结构

```text
Subtitle_Tool/
├── main.py              # 程序入口：负责 GUI 界面与拖拽交互
├── processor.py         # 逻辑核心：负责不同格式字幕的解析与清洗
├── build_exe.py         # 构建脚本：一键打包成单文件 EXE
├── requirements.txt     # 依赖清单：记录项目运行所需的库
└── README.md            # 项目说明文档
```

## 🚀 快速上手 (开发者)

如果你想直接运行源码或进行二次开发，请参考以下步骤：

### 1. 环境准备
推荐使用 **Conda** 或 **venv** 创建独立的 Python 环境：

```bash
# 创建环境 (以 Conda 为例)
conda create -n subtitle_env python=3.10
conda activate subtitle_env

# 安装依赖
pip install -r requirements.txt
```

### 2. 启动程序
```bash
python main.py
```

### 3. 打包分发
如果你想生成不依赖 Python 环境的 `.exe` 文件：
```bash
python build_exe.py
```

## 🛠️ 技术实现点

- **正则提取**：使用 `re` 模块高效清洗字幕中的复杂样式指令。
- **模块化架构**：采用“大脑（逻辑）与皮囊（界面）分离”的设计模式，易于后期增加更多格式支持。
- **路径清洗**：针对 Windows 系统拖拽路径带引号或大括号的情况进行了自动修剪。
