# Subtitle Tool (v1.5.0)

一个基于 CustomTkinter 构建、专为创作者与研究员设计的全能型现代化字幕处理工具。支持全界面拖拽交互、智能多模式切换以及剪映草稿一键快速解析。

---

## ✨ 核心特性

*   **现代化 UI 交互**：采用 macOS 风格的圆角卡片布局，全面适配 Windows DPI 高清缩放，支持系统级 Light/Dark 模式无缝跟随。
*   **全局丝滑拖拽**：基于内置拖拽内核，无论是字幕文件还是剪映草稿 JSON，直接拖入右侧卡片区域即可瞬间自动解析。
*   **一键草稿定位**：专为剪映用户设计，支持一键直达剪映 Windows 本地草稿目录，告别繁琐的寻找路径过程。

---

## 🛠️ 三大核心模式

### 1. 文本提取 (-> TXT)
*   **应用场景**：提取纯文稿进行文献分析、内容归档或 AI 翻译。
*   **输入输出**：`.ass` / `.srt` ➔ `.txt`
*   **技术特点**：深度清洗，自动剥离所有标准时间轴、高级特效标签、样式配置以及空白噪声。

### 2. 格式互转 (ASS ↔ SRT)
*   **应用场景**：解决播放器、剪辑软件或压制软件之间的字幕格式兼容性问题。
*   **输入输出**：`.ass` ↔ `.srt` (智能双向识别)
*   **技术特点**：高精度保留微秒级时间轴，自动重构时间戳格式，确保音画同步。

### 3. 剪映 JSON 转 SRT
*   **应用场景**：提取剪映自动识别的语音字幕，导出为通用格式以便二次编辑。
*   **输入输出**：`draft_content.json` ➔ `.srt`
*   **技术特点**：解析微秒级序列存根，智能合并断句切片，一键生成标准 SRT 文本。

## 🚀 快速启动

### 环境依赖
项目运行需要以下 Python 环境生态（推荐使用虚拟环境）：
```bash
pip install customtkinter tkinterdnd2

```

### 运行程序

```bash
python main.py

```

---

## 📋 使用说明

1. 启动工具后，点击左侧侧边栏切换你需要的**核心模式**。
2. 将符合格式的文件直接**拖入右侧圆角投放区**。
3. 解析完成后，生成的目标文件会自动保存在**原文件所在的同级目录下**，并伴随视觉颜色状态反馈（✨ 绿色代表成功 / 💥 红色代表异常）。
